A simple Python project that evaluates password strength using **entropy** and **common pattern checks**.  
It classifies passwords as **Weak**, **Moderate**, or **Strong**.

## 🚀 Features
- Detects weak patterns like `123`, `password`, `qwerty`, etc.
- Calculates entropy based on password length and character set.
- Classifies passwords into three levels: Weak, Moderate, Strong.
- Provides instant feedback when you enter a password.
